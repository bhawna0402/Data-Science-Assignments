# Student Marks Data Analysis

## Project Overview

This project performs basic data analysis on student marks using Python, Pandas, and Matplotlib.

The objective is to calculate descriptive statistics and visualize the distribution of student scores.

---

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Dataset

The dataset contains marks of students in three subjects:

- Maths
- Science
- English

File used:
student_marks.csv

---

## Tasks Performed

### 1. Loaded Dataset
The dataset was loaded using Pandas.

### 2. Descriptive Statistics Calculated

- Mean
- Median
- Mode
- Standard Deviation

### 3. Data Visualization

Created visualizations using Matplotlib:

- Histogram of marks distribution
- Bar chart of average marks per subject

---

## Key Insights

- Average marks range between 75 and 85.
- Science has the highest average marks.
- Student performance is consistent across subjects.
- No extreme outliers were observed.

---

## Conclusion

Students performed well overall, with balanced performance across all subjects.
